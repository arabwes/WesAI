## Guidelines

- Keep hero images below roughly 300 KB and card images below 150 KB.
- Prefer WebP for new photography; JPEG remains appropriate for images already efficiently compressed.
- Match every image's `alt` text to the actual subject when replacing an asset.
- Confirm usage rights before adding photos from any source outside Shibam's owned brand library.
