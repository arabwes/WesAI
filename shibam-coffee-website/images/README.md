# Images

The public pages use the assets in this folder. Keep each page's image path and alt text aligned with the photo when replacing an asset. The social sharing image is `og-image.jpg` (1200 x 630 pixels).

Photos used on the site: `hero-storefront.webp`, `signature-pastry-drink.webp`, `coffee-service.webp`, `dessert-spread.webp`, `barista-at-counter.webp`, `shibam-cover.webp`, `heritage-shibam-city.jpg`, and `app-preview.webp`.

Use compressed WebP for page photos where possible and check image sizes before shipping. Every referenced image must be present in this folder before build.
