    Inventory Count

    Count everything in the kitchen and in storage. Work through it room by room — the sections are grouped by where each item lives.

    Dessert Inventory

    Log how many of each dessert we have on hand and note any new deliveries that arrived today.
  • As needed

    Local Order List

    Request a run to the local market. Check every item first so we place one full order instead of several small ones.
